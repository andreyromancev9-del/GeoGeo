# 🌍 Geo Screen Analyzer

Мини-программа: по нажатию **Alt + X** делает снимок экрана, распознаёт
текст (Tesseract OCR) и через агрегатор **Polza AI** определяет
**СТРАНУ** и **ГОРОД**, к которым относится открытая страница.

## Возможности
- 📸 Скриншот всего экрана по горячей клавише Alt+X
- 🔍 OCR-распознавание текста (русский + английский)
- 🤖 Анализ через Polza AI (OpenAI-совместимый API)
- 🖼️ Красивое тёмное окно результата (карточки: Страна / Город / Обоснование)
- ⏳ Защита от повторного запуска во время анализа

## Установка
1. `pip install -r requirements.txt`
2. Установите Tesseract OCR с языками `rus` и `eng`.
3. Скопируйте `.env.example` → `.env`, впишите `POLZA_API_KEY`.

## Запуск
- Windows: `python screen_analyzer.py`
- Linux:   `sudo python3 screen_analyzer.py`

Нажмите **Alt+X** — через несколько секунд появится окно с ответом:
какая это **страна** и какой **город**. Выход — Ctrl+C.

## Настройки (в начале screen_analyzer.py или через .env)
| Переменная | Описание | По умолчанию |
|---|---|---|
| `POLZA_API_KEY` | ключ Polza AI | — |
| `API_BASE_URL` | эндпоинт | `https://api.polza.ai/v1` |
| `POLZA_MODEL` | модель | `gpt-4o-mini` |
